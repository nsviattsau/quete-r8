# Quête R-8

Quête d'anniversaire interactive pour enfants (6–8 ans) : le robot R-8 s'est écrasé, et l'équipe de secours répond à ses questions pour retrouver les pièces cachées dans la maison.

- Bonne réponse : la cachette de la pièce s'affiche et l'énergie du robot monte.
- Mauvaise réponse : alarme, et le robot recule d'une étape.
- **Mode parent** (bouton en bas) : saisir ses propres cachettes, enregistrées sur l'appareil.

Une seule page HTML, sans dépendance. Ouvrir `index.html` dans un navigateur ou via GitHub Pages.
